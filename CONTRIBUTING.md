Unless you explicitly state otherwise, any contribution intentionally submitted for
inclusion in this project, as defined in the Apache-2.0 license, is dual licensed
under `Apache-2.0 OR MIT`, without any additional terms or conditions.

Salvo que digas explícitamente lo contrario, toda contribución enviada para incluirse
en este proyecto, según la definición de la licencia Apache-2.0, queda bajo la doble
licencia `Apache-2.0 OR MIT`, sin términos ni condiciones adicionales.

## Developer Certificate of Origin (DCO)

Every commit must be signed off (`git commit -s`), certifying the
[Developer Certificate of Origin 1.1](https://developercertificate.org/). There is no CLA.

Cada commit debe ir firmado (`git commit -s`), certificando el
[Developer Certificate of Origin 1.1](https://developercertificate.org/). No hay CLA.

## Setup / Preparación

```bash
git config core.hooksPath .githooks
git config commit.template .gitmessage
```
